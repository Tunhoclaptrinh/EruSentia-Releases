## Desktop downloads

- Download the platform-specific installer from **Releases**.
- Compare the file hash with `SHA256SUMS.txt` before installing.
- Beta installers are not yet code signed or notarized.
- Windows x64, Linux x64, macOS Apple Silicon (arm64).

This repository contains distribution information only. The application source
code is proprietary and is maintained separately in a private repository.
GitHub automatically adds source archive links to releases; those archives
contain only this public README, not the application source or installers.
